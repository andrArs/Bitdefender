# Random Forest Trees

1. A random forest combines many decision trees to reduce overfitting.
2. Each tree sees a different bootstrap sample of the training data.
3. At each split, the algorithm considers only a random subset of features.
4. Voting across trees makes the final prediction more stable.
5. Random forests work well for tabular data and feature importance demos.
6. They are often easier to explain than boosted ensembles for beginners.
7. A single tree can overfit, while a forest averages away some noise.
8. Classification forests vote on labels and regression forests average values.
9. Students can compare forests with neural models on structured datasets.
10. The randomness in the forest is what helps the ensemble generalize.
11. Feature importance can show which inputs mattered most in a prediction.
