# Convolutions and Images

1. Convolutions look at local pixel neighborhoods instead of the whole image at once.
2. A kernel is a small matrix that slides over the image and computes weighted sums.
3. Edges, corners, and textures are common features learned by early convolution layers.
4. Padding helps preserve spatial dimensions when the kernel reaches the border.
5. Stride controls how far the kernel moves on each step across the image.
6. Pooling reduces spatial size and can make features more robust to small shifts.
7. Multiple channels let a convolution read RGB images or deeper feature maps.
8. Deeper stacks of convolutions can move from simple edges to object parts.
9. Activation functions add non-linearity so the network can learn complex patterns.
10. Training uses backpropagation to adjust kernels so the feature maps improve.
11. Visualization helps students see what each filter responds to in an image.
12. A practical image pipeline often includes resize, normalize, and augment steps.
