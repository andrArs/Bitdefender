# RNN, GRU, and LSTM

1. Recurrent networks process sequences one step at a time and keep a hidden state.
2. RNNs are useful for text, time series, and any ordered data.
3. Vanishing gradients can make long-range dependencies hard to learn.
4. GRU cells simplify recurrence with update and reset gates.
5. LSTM cells add a memory cell and gates that help retain information longer.
6. The hidden state acts like a working memory for the current sequence.
7. Bidirectional recurrent models can read a sequence from both directions.
8. Many sequence tasks need masking so padding tokens do not confuse the model.
9. Teacher forcing can speed up training in sequence-to-sequence systems.
10. RNNs are older than transformers, but they are still useful for teaching recurrence.
