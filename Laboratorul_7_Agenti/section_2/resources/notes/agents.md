# Agents and Tool Use

1. An agent is a system that decides when to call tools instead of guessing.
2. Tool calling turns a language model into a planner that can fetch, write, or search.
3. A coordinator can route tasks to specialized sub-agents with different tool sets.
4. The model can use a transformer backbone while the agent layer handles orchestration.
5. Read tools are safer because they inspect state without changing it.
6. Write tools need more caution because they can modify files, notes, or calendars.
7. An agent loop usually alternates between reasoning, tool call, and observation.
8. MCP gives tools a standard way to be discovered and invoked.
9. A personal assistant agent often manages schedules and reminders.
10. A college buddy agent often searches notes, PDFs, and course material.
11. Good tool descriptions help the model choose the right function quickly.
12. Testing with repeated keywords like transformer, agents, and schedule reveals search quality.
